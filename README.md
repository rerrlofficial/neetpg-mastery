# NEET-PG Master

A medical MCQ learning platform with a student app, admin dashboard, and Supabase backend.

## Project structure

- `apps/student` — student-facing web foundation
- `apps/admin` — admin dashboard foundation
- `packages/shared` — shared question types and validation notes
- `supabase/migrations` — database migrations
- `.env.example` — environment variable reference

## Current status

Phase 1 foundation only. Authentication, database connection, spreadsheet import, and production deployment are not configured yet.

## Next milestones

1. Supabase schema and authentication
2. Admin Excel/Google Sheets import
3. Student MCQ practice flow
4. Explanations, bookmarks, and progress tracking
5. Android packaging and deployment
